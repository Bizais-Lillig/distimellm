# distimellm
Automated timeline extraction in English, Standard Modern Chinese, and Classical Chinese: A hackathon organized by the Huma-Num consortium distam+ on the invitation of the CEFC Taipei and the BFT in Taipei (21-24 September 2026).

A sample of the dataset is available in ```dataset```.

The JSON output structure and comments about its organization is available in ```output_structure```.

The prompts designed to extract, document and organize temporal data from the texts are stored in ```structure_prompt```.

The notebooks run to produce the JSON files are stores in ```LLMs```.

The metrics and notebooks created to evaluate the results of the experiments are provided in ````evaluation``.

Some documentation and reflection on the task are present in ```for_reference```.
