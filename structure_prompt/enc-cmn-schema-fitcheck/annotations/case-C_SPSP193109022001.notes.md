## Case C: technically fills, but not really

The real subject of the article is actually 上海扶輪社 (the club holding the event), not the invited Andrews, the only person mentioned, and a club can't be a key at all, which would be true for most of `rotary`. `time_start` has to stay `Null`, since the only date given ("明日", tomorrow) is relative to the newspaper's own date, and the old schema has no way to use that. Against the current schema: `utterance_time` now lets "明日" resolve to an actual date, and the club-as-key problem is gone too (key is a corpus path, not a person).

> The club only shows up as a file path, never as the thing the events are actually about.
