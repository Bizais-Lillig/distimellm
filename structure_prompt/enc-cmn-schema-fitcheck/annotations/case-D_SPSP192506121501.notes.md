## Case D: couldn't annotate at all (old schema)

It's a telegram between two Rotary clubs, and no person is named anywhere. The old schema needs a person's name as the key, so there's nothing to put there without making one up, which would be worse than leaving it blank. The only time expression, "日前" ("a few days ago"), is also relative to the paper's own date, and the old schema can't use that either. The current schema fills it well. The key is a corpus path now, not a person, so the missing-subject problem goes away. 

> "日前" is vague, but the XX convention keeps the month: `1925-06-XX`.
