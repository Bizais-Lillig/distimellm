# enc-cmn-schema-fitcheck — original-schema fit-check on ENC/cmn

Four documents chosen by me to stress the schema, tried by hand during the afternoon session against the original schema (`d8ac056`, before this branch's changes). This folder writes those tries up in detail, as a complement to the ENC/zh entry in `Notes_output_and_prompt.md`. The JSON, written out with an LLM and checked against the texts, is there to show where the schema breaks, not as gold annotations. Texts in `texts/`, JSON + notes per case in `annotations/`. I also tried the new schema on the same documents with LLM-drafted annotations, which I reviewed (pilots for the adoption discussion, not gold), in the repo-root `/annotations/`: `annotations_enc_exp_cmn_SPSP192606271118.json`, `annotations_enc_exp_cmn_SPSP192708311019.json`, `annotations_enc_rotary_cmn_SPSP193109022001.json`, `annotations_enc_rotary_cmn_SPSP192506121501.json`.

Against the current schema: the top-level key moved from a person's name to a corpus path (`"ENC/exp/cmn"`, like CMallart's `"ENC/rotary/eng"`), that fixes B, C, and D below, without anyone forcing it.
